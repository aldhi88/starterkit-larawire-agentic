# Security Policy

## Supported versions

Security fixes are provided for the latest published release. Upgrade the
Laravel host through Composer and verify it locally before production deploy.

## Reporting a vulnerability

Please use GitHub's private **Security advisories → Report a vulnerability**
flow for this repository. Do not open a public issue containing exploit steps,
credentials, personal data, environment files, database dumps, or production
URLs.

Include the affected version, impact, minimal reproduction, and suggested
mitigation when known. Redact all real secrets and user data. A report does not
authorize access to systems or data you do not own or have permission to test.
